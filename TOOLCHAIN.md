# Toolchain

The committed Solidity verifier (`contracts/src/LeashVerifier.sol`) and proof fixture
(`contracts/test/fixtures/`) are generated by, and only valid for, this exact toolchain:

| Tool  | Version         |
|-------|-----------------|
| nargo | 1.0.0-beta.16   |
| bb    | 3.0.1           |

`circuits/Nargo.toml` has no `compiler_version`: nargo only accepts full releases there, so it cannot
name `1.0.0-beta.16`. `scripts/gen-proof-fixture.sh` enforces the versions instead.

## Install

The scripts and the root `pnpm test` / `pnpm test:circuits` use `./.tools/nargo` and `./.tools/bb`
by default. `.tools/` is git-ignored, so each checkout has to fetch its own copies:

```sh
# Option A: install with the official installers, then copy the binaries in
noirup -v 1.0.0-beta.16
bbup -v 3.0.1
mkdir -p .tools
cp ~/.nargo/bin/nargo .tools/nargo
cp ~/.bb/bb .tools/bb

# Option B: leave your global installs alone and unpack the release archives for your
# platform from the GitHub releases instead:
#   nargo: https://github.com/noir-lang/noir/releases/tag/v1.0.0-beta.16
#   bb:    https://github.com/AztecProtocol/aztec-packages/releases/tag/v3.0.1 (barretenberg-*.tar.gz)
# then put the `nargo` and `bb` executables at .tools/nargo and .tools/bb.

.tools/nargo --version   # nargo version = 1.0.0-beta.16
.tools/bb --version      # 3.0.1
```

To use binaries somewhere else, set `NARGO=/path/to/nargo BB=/path/to/bb`.

## Regenerate the verifier and fixture

```sh
./scripts/gen-proof-fixture.sh          # or: pnpm gen:fixture
```

The script exits with an error unless `nargo --version` reports 1.0.0-beta.16 and `bb --version`
reports 3.0.1. It compiles `circuits/` and `packages/core/policy_circuit`, writes the EVM (keccak
oracle hash, `-t evm`) verification key and `contracts/src/LeashVerifier.sol`, plus the default-target
key in `circuits/target/vk/` (git-ignored) that the off-chain verifier in `packages/core` uses, and
prints both `vk_hash` values. `scripts/gen-fixtures.cjs` then proves each forge test case with
`@leash/core`, checks it with `bb verify`, and writes `contracts/test/fixtures/<case>/`.

Then run:

```sh
cd contracts && forge test -vv
```

`packages/core` (prover, verifier, and its tests) runs `$NARGO` / `$BB` if set, else `.tools/nargo` and
`.tools/bb` when present, else `nargo` / `bb` from `PATH`. The root test script also uses `.tools`:

```sh
PATH="$PWD/.tools:$PATH" pnpm test
```
